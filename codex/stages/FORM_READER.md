# Grouped form driver

Under the active lease, call `codex/jr form_session '{"job_key":"OPENING_KEY"}'`. Keep the employer tab at the original application. Open the returned loopback address in a second tab. In the browser host, import `job_runtime/hosted_form_driver.mjs` from the absolute path of this checkout and call `drive(applicationTab, plannerTab)`.

The driver observes the controls, asks the planner for saved answers, fills supported inputs, verifies the readback and advances eligible pages. It returns the private proof file for the final-review checks. Preserve conflicts and unresolved labels. The final submission requires the separate submission operation and reconciliation.
