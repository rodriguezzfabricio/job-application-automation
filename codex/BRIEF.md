# Run one application worker

Use `codex/jr gate` to preview the available budget and queue. Local setup belongs under `JOB_AUTOMATION_PRIVATE_ROOT`. A scheduled worker holds the lease for browser actions, dashboard updates and submission.

1. Supply a fresh dashboard snapshot to `codex/jr begin SNAPSHOT.json`. Read `codex/jr brief` for the funded operations and the current opening.
2. Complete the discovery and matching stages selected for the run. Check the employer's original publication date, availability, prior history and pending clicks.
3. Enroll an eligible opening with `canary_enroll`. Use the documented grouped form driver to observe and fill its draft.
4. Verify the selected résumé and answer evidence against the same opening. A fresh dashboard command packet and durable `submit_started` record precede a single authorized click.
5. Reconcile the result from a receipt, record each stage outcome, mirror the verified changes and call `finish`. An uncertain submission stays pending until an independent observation resolves it.
